# Carpeta de imágenes

Esta carpeta queda lista para incorporar fotografías, portadas, logotipo y recursos propios de Desconcertados Studios.

Las imágenes de esta versión de demostración se cargan desde URLs de Unsplash. Para alojarlas localmente:
1. Copia las imágenes autorizadas a esta carpeta.
2. Cambia cada `src="https://images.unsplash.com/..."` por una ruta como `img/mi-foto.jpg`.
3. Para la imagen de fondo principal, busca `.hero-image` en `css/styles.css` y reemplaza la URL de `background-image`.
